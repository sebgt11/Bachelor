for at køre koden skal du bruge terminalen, compile via:

gcc Baseline.c -o Baseline -lm

og så kør med:

./Baseline



CreateDataset.py:
Laver et rigtigt stor kollektion and set af tal. Output: dataset.csv

GenerateBitvectors.py: 
Tager al de sets og laver dem om til bitvector represenations af de sets. Output: bitvectors.csv
