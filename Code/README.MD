# Containment Entropy

Code for the bachelor thesis on storing collections of sets compactly using containment entropy.

## Files

- `Baseline.h` - the shared compressed bitvector (block based rank, select and access). The containment program uses this.
- `Baseline.c` - a small standalone demo. Encodes the example set from the report and prints the resulting arrays (C, O, L, R, P, S).
- `CEB.c` - the containment program. Builds the hierarchy, stores each set relative to its parent, generates the synthetic test data, and runs all the experiments. Writes `results.csv`.
- `CEBTemp.c` - a small standalone demo of the containment program. Builds the hierarchy on the same example sets from the report and prints the stored structure (the hierarchy plus C, O, L, R, P, S per bitvector), then shows retrieve and rank on the smallest set. No data generation or experiments.
- `plot_results.py` - reads `results.csv` and makes the figures (into a `figures/` folder) and `summary_table.csv`.
- `results.csv` - the raw output of the experiments (one row per configuration).
- `summary_table.csv` - averaged numbers, regenerated by the plot script.

## How to run

Compile and run the containment experiments (this also generates the data and writes `results.csv`):

```
gcc CEB.c -o ceb -lm
./ceb
```

Make the figures and the summary table from that output:

```
python3 plot_results.py
```

Run the baseline encoding demo on its own:

```
gcc Baseline.c -o Baseline
./Baseline
```

Run the containment demo on the example sets (prints the hierarchy and stored arrays, no experiments):

```
gcc CEBTemp.c -o cebtemp -lm
./cebtemp
```

Python needs `numpy` and `matplotlib`.
